# Retained research inputs

These directories contain exposed historical inputs, not the product quickstart.
Use [the local product example](../docs/QUICKSTART.md) to try DUO.

| Directory | Contents |
|---|---|
| `benchmarks/docs_qa/` | Frozen question sets, specification and the attributed DSH documentation snapshot |
| `experiments/` | Original docs-QA contract and deterministic legacy mock configuration |

Research scripts remain in [scripts/research](../scripts/research/); outcomes and
historical guides are indexed in [docs/research](../docs/research/README.md).
The `docs_qa.yml` contract retains its original run settings and budget text as
historical evidence. They grant no current permission to run, resume or spend.
The archived holdout/final inputs are exposed data, never fresh unseen evidence.

Files were relocated without editing their bytes. Old relative paths belong to
their recorded commits; the [migration map](../docs/development/HOMEPAGE_MIGRATION.json)
records current locations. Private run archives and ledgers are not distributed.
No experiment was rerun for this repository cleanup.
