# Current product coverage

[Current architecture](docs/ARCHITECTURE.md) maps the native runtime and its
extension boundaries. [Current capabilities](CURRENT_STATUS.md) are generated
from runtime discovery metadata. The [maintenance queue](docs/product-foundation/QUEUE.md)
links current release work and sealed earlier Goals; the
[0.4.0 architecture audit](docs/product-foundation/AUDIT.md) records that
historical baseline rather than current release acceptance.

[Previous design coverage](docs/history/0.4.0/DESIGN_COVERAGE.md) is an unchanged historical snapshot; old Goals/results remain closed at their original evidence boundaries.
