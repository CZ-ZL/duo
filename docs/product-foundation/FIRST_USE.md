   but registry dependencies still failed before TLS. Zero model requests. No TLS

   DSH host's dependencies. It passed in a new profile and was then exposed in the
   bilingual guide. [OFFLINE_INSTALL.json](./first-use/OFFLINE_INSTALL.json) records
   actual public commands through report retrieval, without model calls.

   with zero implementer help, but the three correctly extracted fact answers
   carried backticks. The frozen v1 evaluator scored both versions 1/4. These
