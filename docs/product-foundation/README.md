`QUEUE.md`, `LEAN.md` and other status prose are retained attempt records. They
are not a current task dispatcher. A previous live acceptance or budget does not
authorize another run. The [historical record map](../history/README.md) explains
old relative references and private inputs without changing the sealed files.
